# #6 API Error: 403 Request not allowed

| 字段 | 内容 |
| --- | --- |
| 报错原文 / 现象 | API Error: 403 Request not allowed |
| 平台 | 通用 |
| 人话解释 | 订阅未生效、账号没有 Claude Code 权限，或公司代理拦截。 |
| 出处 | https://code.claude.com/docs/en/troubleshoot-install |
| 实测记录 | 待 Mac 实测 |

## Mac 修复步骤

1. 核对订阅与账号权限
2. 排查公司代理/网关是否拦截
3. 对照官方排障页

## 备注

地区/账号限制类问题只给官方支持名单与条款，不提供任何绕过方法。
