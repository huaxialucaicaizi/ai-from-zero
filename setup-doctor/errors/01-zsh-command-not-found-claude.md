| 字段 | 内容 |
| --- | --- |
| 报错原文 / 现象 | zsh: command not found: claude |
| 平台 | Mac |
| 人话解释 | 装好了，但系统找不到 claude 在哪（PATH 没配好）。 |
| 出处 | https://code.claude.com/docs/en/troubleshoot-install |
| 实测记录 | 待 Mac 实测 |

## Mac 修复步骤

1. 确认安装方式（官方 install.sh 或 brew cask）
2. 重新打开终端后再执行 `which claude`
3. 按官方排障页检查 PATH
