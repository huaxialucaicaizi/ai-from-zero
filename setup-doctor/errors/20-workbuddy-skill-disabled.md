# #20 WorkBuddy：技能已安装但关闭后新任务调不到

| 字段 | 内容 |
| --- | --- |
| 报错原文 / 现象 | WorkBuddy：技能已安装但关闭后新任务调不到 |
| 平台 | WorkBuddy |
| 人话解释 | 关闭后仍在已安装列表，但不再参与新任务调用；已加载到当前会话的仍可用，新会话才完全生效。 |
| 出处 | https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Skills-Market |
| 实测记录 | 待 Mac 实测 |

## Mac 修复步骤

1. 在技能市场确认已启用
2. 开新会话再试
3. 对照官方「启用/关闭技能」说明

## 备注

地区/账号限制类问题只给官方支持名单与条款，不提供任何绕过方法。
