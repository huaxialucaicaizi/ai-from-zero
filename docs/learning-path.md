# 学习路径 / Learning Path

知道看什么 → 会提问 → 装上工具 → 做出作品 → 用进工作 → 做自己的 skill

| 步骤 | skill | 说明 |
| --- | --- | --- |
| 知道看什么 | `ai-sources` | 一手官方源 + 课程避坑标准 |
| 会提问 | `prompt-coach` | 最多 3 问，写出可复制提示词 |
| 装上工具 | `setup-doctor` | Mac 自检 + 报错库（目前仅 Mac） |
| 做出作品 | `first-build` | 单文件网页（v0.1 骨架） |
| 用进工作 | `ai-for-my-job` | 按岗位给 3 个场景；也是第二入口 |
| 做自己的 skill | `skill-maker` | 把常用提示词打包（v0.1 骨架） |

办公向的 PPT / 数据分析 / 设计 / 视频挂在「用进工作」之下，分仓库推进，本仓库用「规划中」指向。
