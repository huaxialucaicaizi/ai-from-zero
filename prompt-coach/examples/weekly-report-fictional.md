# 虚构示例：把周报提示词写清楚

> 本页全部为虚构示例。

## 用户原话

> AI 写的周报太空了，指令怎么改？

## 教练追问（≤3）

1. 目标：只要「本周做了什么 + 风险」，还是要数据？
2. 读者：直属领导还是跨部门？
3. 格式：字数、是否分条？

（假设用户答：给直属领导；先结论；200 字；不要夸张形容词。）

## 可复制提示词

```text
你是助理，根据我粘贴的工作要点写一份周报。
读者：直属领导。结构：①一句话结论 ②本周 3 条进展 ③1 条风险与求助。
篇幅：200 字左右。不要形容词堆砌，不要编造未提供的数据。
要点：
---
（在此粘贴）
---
```

## 逐块说明

- 角色：限定口吻，避免写成营销文。
- 任务 + 结构：对应「格式」积木，减少答非所问。
- 约束「不编造」：降低幻觉。

**理由：** 先固定读者和结构，比反复说「写专业一点」更有效。
