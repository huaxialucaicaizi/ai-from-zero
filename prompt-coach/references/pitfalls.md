# 常见坑 + 自检清单

## 常见坑

1. **只有动词没有对象**：「帮我优化一下」→ 说清优化什么、给谁看、什么叫好。
2. **形容词堆砌**：「专业、高端、颠覆」→ 换成可检查的结构或样例。
3. **不给材料却要精确数字** → 让用户粘贴，或允许「待确认」。
4. **一次塞进十个任务** → 拆成多轮，或明确优先级。
5. **没说不要什么** → 容易出现编造客户名、承诺时效、法律结论。
6. **把模型当成已联网事实库** → 需要一手来源时改用 `ai-sources` 或让用户贴原文。

## 交付前自检（5 条）

- [ ] 目标说清了吗？
- [ ] 读者说了吗？
- [ ] 格式说了吗？
- [ ] 给了材料吗？
- [ ] 说了不要什么吗？
