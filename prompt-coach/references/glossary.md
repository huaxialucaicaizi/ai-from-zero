# AI 黑话术语表（首批 12 个）

每个词：一句人话 + 一个办公例子。不编造精确参数。

| 词 | 人话 | 办公例子 |
| --- | --- | --- |
| token | 模型计费/截断时用的文字小片，大约和字词相关，但不是严格「一个汉字=一个 token」 | 周报太长被截断，往往是上下文里 token 不够用了 |
| 模型 / 大模型 | 根据提示生成文字或别的内容的 AI 程序 | 用聊天框写通知，背后就是某个模型在回答 |
| 提示词 | 你发给 AI 的说明和要求 | 「写给家长的通知，150 字内」就是提示词 |
| 上下文窗口 | 一次对话里模型能「看见」的内容上限 | 贴了整本手册后它开始忘掉开头，可能触顶了 |
| 幻觉 | 模型编得像真的，但无依据 | 虚构了客户公司名称写进方案 |
| 多模态 | 能处理文字以外的输入/输出，如图片 | 把报错截图发给能识图的 AI |
| Agent | 能按目标多步调用工具完成任务的 AI 用法 | 让助手读文件、改草稿、再跑检查 |
| MCP | 一种让 AI 接外部工具/数据源的协议思路（细节以你用的产品文档为准） | 让 AI 经授权查询内部文档库 |
| skill | 一段可安装的说明书（常含 SKILL.md），告诉 AI 何时、如何按流程做事 | 安装 prompt-coach 后，一提「改提示词」就按教练流程走 |
| API | 程序之间约定好的调用接口 | 用官方接口而不是手工点网页来发请求 |
| API Key | 调用 API 时的密钥，等同于密码 | Key 填错会看到 401 |
| 插件 / 连接器 | 产品里扩展能力的附加模块（名称因产品而异） | 在聊天产品里打开「浏览」或「表格」类扩展 |

出处（术语无单一标准定义页时，以各厂商文档为准；上表为人话解释，不替代官方定义）。
