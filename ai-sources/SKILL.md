# ai-sources · 信息源导航 + 课程避坑

学习路径位置：**知道看什么**（入门第一步）。

## 何时使用

- 问学 AI 看谁、看什么、有没有靠谱课
- 贴来付费课或博主页面，想做避坑评估

## 不要用这个 skill

- 写作、安装排障、岗位场景推荐（用其他 skill）
- 编造粉丝数、收入承诺或未在页面出现的信息

## 工作流

1. **判断帮助类型**：要信息源 → 第 2 步；贴了页面 → 第 3 步。
2. **按阶段推荐**：问一句所处阶段（刚听说 / 会用聊天 / 想装工具），从 `sources.md` 取分组；一手官方源永远排第一。第一版 **只含官方一手源**，不含博主名单。
3. **逐条评估**（贴了课程/博主页）：按 `references/criteria.md` 与 `references/course-review.md`。页面没写的一律「未知」，不替页面补信息。
4. **输出**：每条「符合 / 不符合 / 未知」+ 页面原文证据；结论「值得 / 谨慎 / 不建议」+ 一句理由。
5. **讲理由**：说明为什么把官方源放第一，或为什么某条标未知。

## 读哪些文件

- `sources.md`：一手官方源列表
- `references/criteria.md`：判断标准
- `references/course-review.md`：课程评估输出格式
