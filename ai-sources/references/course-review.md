# 课程 / 页面避坑 · 评估流程与输出格式

## 流程

1. 让用户粘贴页面关键文字，或提供能识图的 AI 可读截图。
2. 按 `criteria.md` 逐条打标：符合 / 不符合 / 未知。
3. 每条附 **页面原文摘录** 作证据（不要改写后再当证据）。
4. 汇总结论：值得 / 谨慎 / 不建议 + 一句理由。
5. 若官方免费源已能覆盖其大纲，在理由里写明，并指向 `sources.md`。

## 输出模板

```text
## 评估对象
（课程名 / URL / 粘贴摘要）

## 逐条
1. …：符合 / 不符合 / 未知
   证据：「…」
…

## 结论
值得 / 谨慎 / 不建议
理由：…
```
