# weekly-report-helper（虚构示例）

> 虚构示例：演示 skill-maker 的产出形态，不是真实业务 skill。

1. 让用户粘贴本周要点。
2. 输出：一句话结论 + 3 条进展 + 1 条风险。
3. 不编造未提供的数据。
4. 交付后用一两句话说明为什么先写结论（读者是领导，先看结果）。
