# first-build · 做出第一个作品（v0.1 骨架）

学习路径位置：**做出作品**。  
状态：**v0.1 骨架** — 目录与流程草稿已齐，模板与 Mac 实测待补。

## 何时使用

- 一句话想做个人网页、小工具、小游戏
- 需要每步讲清在做什么，最后能截图或分享链接

## 不要用这个 skill

- 修改公司或线上生产代码
- 对比建站平台付费套餐、写 Word 简历等非「单文件作品」需求

## 工作流（草稿）

1. 问清：想做什么、给谁看。
2. 选模板：`templates/personal-page/` 或 `templates/mini-tool/`（加班费计算器等）。
3. 生成**单个 HTML 文件** → 浏览器打开 → 按反馈改一处并说明改了什么。
4. 分享：截图；或按 GitHub Pages 官方文档发布（需 GitHub 账号）。国内访问情况 **待 Mac 实测 / 待核实**。
5. 讲理由：为什么选单文件（零基础可双击打开、依赖最少）。

## 依赖

能写文件的 AI 工具 + 浏览器；分享链接需 GitHub 账号；第一版在 Mac 实测。
