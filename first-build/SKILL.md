# first-build · 第一个作品

学习路径位置：**做出作品**。

## 何时使用

- 一句话想做个人网页、小工具、小游戏
- 需要每步讲清在做什么，最后能截图或分享链接

## 不要用这个 skill

- 修改公司或线上生产代码
- 对比建站平台付费套餐、写 Word 简历等非「单文件作品」需求

## 工作流

1. 问清：想做什么、给谁看。
2. 选模板：`templates/personal-page/`（个人网页）或 `templates/mini-tool/`（加班费计算器示例）。
3. 生成或改写**单个 HTML 文件** → 用浏览器打开 → 按反馈每次只改一处，并说明改了什么。
4. 分享：先截图；若要链接，按 `references/share.md` 与 GitHub Pages 官方文档操作（需 GitHub 账号）。国内访问是否稳定：**待核实**；完整流程 **待 Mac 实测**。
5. 讲理由：为什么选单文件（零基础可双击打开、依赖最少）。

## 依赖

能写文件的 AI 工具（推荐 Claude 桌面版）+ 浏览器；分享链接需 GitHub 账号；第一版在 Mac 上引导，Windows 流程下一版。

## 读哪些文件

- 模板：`templates/personal-page/index.html`、`templates/mini-tool/index.html`
- 分享：`references/share.md`
