# 虚构示例：一句话做个人网页

> 本页全部为虚构示例。

## 用户原话

> 我想做一个自己的个人网页，给朋友看看我在学 AI。

## 直接问 AI（对比前）

得到一大段多文件项目或框架说明，零基础不知道先打开哪个文件。

## 用 first-build（对比后）

1. 选 `templates/personal-page/index.html`
2. 把「小周」改成用户名字，保留单文件
3. 浏览器打开确认
4. 截图分享；若要链接，按 `references/share.md` 走 GitHub Pages（**待 Mac 实测**）

**理由：** 单文件可以双击打开，失败面最小，适合第一个作品。
