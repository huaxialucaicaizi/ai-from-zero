# 分享作品

## 方式一：截图（最快）

1. 用浏览器打开 HTML 文件。
2. 截图发给同事或朋友。

## 方式二：GitHub Pages（需要 GitHub 账号）

按官方文档操作：[GitHub Pages](https://docs.github.com/pages)。

常见步骤（以官方当前界面为准，文案可能变化）：

1. 新建仓库，把 `index.html` 放进仓库（可放在根目录或 `docs/`）。
2. 在仓库设置里打开 Pages，选择分支与目录。
3. 等待部署完成后打开生成的链接。
